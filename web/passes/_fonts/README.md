Fonts used to draw text on the Apple Wallet stamp strips (lib/stampStrip.ts), so the server never depends on system fonts.
All under the SIL Open Font License 1.1 (licence texts beside them).
- Geist-Regular.ttf (Vercel), copied from next's bundled @vercel/og: Latin labels.
- BodoniModa.ttf (variable), google/fonts ofl/bodonimoda: the reward step numbers (3, 6, 9).
- Tajawal-Medium.ttf, Tajawal-Bold.ttf, google/fonts ofl/tajawal: Arabic text.
- LibreBaskerville.ttf (variable), google/fonts ofl/librebaskerville: the type wordmark on Wallet images (scripts/pass-art-type.mjs).
- NotoNaskhArabic.ttf (variable), google/fonts ofl/notonaskharabic: Arabic names on Wallet images (scripts/pass-art-type.mjs).
