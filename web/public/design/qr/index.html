Design exploration, sample data

QR code styles

Two jobs: the small till code on each member’s card, read by staff phones at the counter, and the join code on posters, table tents and NFC plates, read by guests’ own cameras. Every style here was decoded by machine before it was allowed on this page.

Recommendation

Member card: Soft corners

Ink modules on a bone plate, level Q, a full four-module quiet zone. It read at every size tested, from 96 to 600 px, clean and after a simulated phone capture. The softened eyes are the only styling: enough to feel made for the card, nothing that costs the scanner.

Why not more: the till code is read in a hurry, in low light, by our own scanner, which reads dark-on-light codes only.

Posters and tents: Crest centre

The same soft-corner code at level H, with the venue crest on a small ink tile in the middle (about 6 to 7% of the code). The crest tells a guest whose code it is before they scan. It read from 128 px up; give it room on print and test the printer’s proof with two different phones.

Alternative: Gold plate, for a poster where bone looks too bright. It also read at every size.

All six styles

Shown with the till code. Each was also made with the join link; the PNGs for both are in png/.

Scan test

Decoded with jsQR, the library the staff scanner uses, set the same way (dark-on-light only). The camera-like capture puts the code on a dark surround, blurs it, dims it and saves it as a low-quality JPEG. Sizes are the whole code including its quiet zone, in pixels. On the web card the code is about 80 CSS px, which is 160 to 240 real pixels on a phone screen.

  • Dots were rejected: they failed at some sizes even at level H.
  • Gold on black was rejected: inverted codes never read in our scanner, and other apps read them only when they try both polarities.
  • Rules for any client: dark modules on a light plate, level Q on the card and H when a mark sits in the middle, four modules of quiet zone, the mark under about 20% of the area (here 6 to 7%).
  • Not tested yet: real phones, real print, and Apple or Google Wallet (Wallet draws its own barcode).
